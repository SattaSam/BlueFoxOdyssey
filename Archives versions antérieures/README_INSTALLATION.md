# Documents de référence BlueFox Odyssey

Cette archive contient :

- `MASTER_BLUEFOX.md` : vision, règles et architecture de référence ;
- `DEV_HISTORIQUE_BLUEFOX.md` : historique des versions et décisions ;
- `TODO_BLUEFOX.md` : tâches à réaliser, classées par priorité.

Installation conseillée :

1. Décompresser l’archive.
2. Placer les trois fichiers `.md` à la racine du projet BlueFox Odyssey.
3. Exécuter :

```powershell
git add MASTER_BLUEFOX.md DEV_HISTORIQUE_BLUEFOX.md TODO_BLUEFOX.md
git commit -m "docs: add BlueFox V0.8 reference documents"
git tag -a v0.8-docs-baseline -m "BlueFox Odyssey V0.8 documentation baseline"
git status
```
